## 新概念/新框架/新协议/新评测

- **GitHub Copilot Harness**：单一 Coding Agent 工作流覆盖原型、规划、实现、审查；重要性在于 Coding Agent 正收敛为统一工程工作台。
- **AgentENV**：大规模 Agent 环境运行系统，支持快照、恢复、分支；重要性在于 Agent 训练和生产运行都需要可恢复环境状态。
- **Skill-driven Agent Architecture**：通过 `SKILL.md`、Skill Registry、MCP Connector、工具循环构建 Agent；重要性在于 Skill 成为可治理工程资产。
- **Multi-agent Session Workspace**：一个工作区内管理多个 Agent 会话和任务上下文；重要性在于多任务 Coding Agent 需要 session isolation 和 progress retention。
- **Agent Merge**：Agent 自动处理 PR 审查反馈和合并冲突；重要性在于 PR 自动化必须接 review trace 和权限门。
- **PerceptionBench**：把视觉感知拆成 10 种原子能力评测；重要性在于 Browser/Computer Use Agent 的失败常发生在感知层。
- **Provider Performance Evaluation**：测量 LLM provider 的延迟、吞吐、正常运行时间和精度；重要性在于 Agent Runtime 要做模型路由和成本治理。
- **Open Secure AI Alliance**：开源 AI 安全与防御联盟；重要性在于安全工具链需要可审查、可定制。
- **Open-weight Model Safety Testing**：对足够强的开源权重模型做强制安全测试；重要性在于本地 Agent Runtime 也需要安全评估。
- **Artifact Skill**：Skill 产出 HTML PPT 等可协作 artifact；重要性在于 Skill completion criteria 需要覆盖产物质量和人类审查。
