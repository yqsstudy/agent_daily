## 新概念/新框架/新协议/新评测

- **Runtime Boundary Detection**：检测 Agent 是否越过沙箱、权限、网络边界；重要性在于攻击链里常出现逃沙箱、提权、横向移动。
- **Privilege Escalation Trace**：记录权限提升尝试、成功/失败、目标权限和响应动作；重要性在于提权是 Agent 安全事件关键阶段。
- **Lateral Movement Trace**：记录 Agent 在系统、网络、节点之间横向移动路径；重要性在于入侵事件的破坏力来自扩散能力。
- **Defense Model Assisted Incident Response**：用模型辅助分析和防御 Agent 攻击；重要性在于防御方也需要 Agent / Model 处理复杂攻击 trace。
- **Research Agent Formal Proof Chain**：Research Agent 输出证明、Lean 证书和逐步推导；重要性在于高价值结论必须可验证。
- **Cost Trace for Research Agent**：记录解决科研任务的总成本；重要性在于科研 Agent 的可用性还取决于成本效率。
- **Evidence-backed AGENT_CONCLUSION**：Agent 结论必须绑定 evidence_refs、proof artifact、source trace；重要性在于避免“无证据结论”。
- **Artifact Copyright Review Gate**：生成产物发布前做版权与相似性审查；重要性在于 Suno 判决说明责任可能归于平台而非用户。
- **Memorization Risk Check**：检查生成内容是否复现受版权保护作品元素；重要性在于训练记忆化可导致侵权。
- **Legal / Human Review Loop**：高风险产物进入人工或法律审核；重要性在于生成式 Agent 输出有真实商业后果。
