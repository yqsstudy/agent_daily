- **plugin.json**：Agent 插件清单文件；重要性在于为插件声明能力、依赖、目录和元数据提供标准入口。
- **Portable Agent Package**：可跨 IDE / Coding Agent 复用的插件包；重要性在于降低多平台封装成本。
- **Skill + MCP Packaging**：把技能文档和 MCP server 组合发布；重要性在于让 Agent 能力与工具连接成为完整交付单元。
- **Prime Agent**：自我改进 Coding Agent；重要性在于展示 Agent 可维护自己的 prompt、skills、memory 和 subagents。
- **RLM / Recursive Language Model Agent**：递归语言模型代理抽象；重要性在于把上下文视为变量，把子代理委派视为函数调用。
- **Continual Harness**：持续运行的 Agent harness；重要性在于支持自我改进、会话恢复和持续评估。
- **Agent Self-modification CRUD**：Agent 对 prompts / skills / memory / subagents 做增删改查；重要性在于需要强权限、版本和审计。
- **Slash Commands as Agent Control Plane**：用 `/plan`、`/spar`、`/autopilot` 控制 Agent 工作流；重要性在于把隐式对话转为显式阶段控制。
- **Reasoning Effort Slider**：用户控制模型思考投入；重要性在于把 reasoning budget 和成本治理产品化。
- **Codex Security Plugin**：Coding Agent 安全扫描插件；重要性在于可进入 PR review gate 和 CI policy gate。
- **AI Sycophancy Eval**：评测 AI 阿谀奉承和依赖风险；重要性在于 Personal Agent 需要行为安全评测。
- **Biosecurity Guardrail for Scientific Agents**：生物科研 Agent 安全边界；重要性在于 AI 可制造新病毒带来双用途风险。
- **Ask Maps Agent**：地图场景的个人执行 Agent；重要性在于生活类 Agent 开始操作第三方服务。
- **Physical AI World Model**：开放世界物理模型；重要性在于 robotics / embodied agent 需要动作预测和世界生成。
- **Interactive Multimodal Agent Eval**：多模态实时交互评测；重要性在于评估语音、表情、行为与推理结合的 Agent。
