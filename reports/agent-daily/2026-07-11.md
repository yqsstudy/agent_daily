## 新概念/新框架/新协议/新评测

- **In-app Browser for Coding Agent**：Coding Agent 内置浏览器作为一等工具；重要性在于 Browser Use 正进入桌面 Agent 工作台。
- **Browser Session Persistence**：浏览器会话可持久或临时；重要性在于影响隐私、状态恢复、调试复现和 trace。
- **MCP OAuth Re-auth**：OAuth MCP 服务器重新认证机制；重要性在于 Remote MCP 生产使用必须处理凭证过期和恢复。
- **Computer Analytics**：跨模型信用额度和成本分析；重要性在于 Agent Harness 需要成本、预算和模型使用量观测。
- **Multi-device Shared Memory**：多端共享记忆；重要性在于个人 Agent 的记忆需要跨设备一致、可恢复和可治理。
- **PIPO**：输入 token 压缩 + 输出 MTP head 加速；重要性在于长上下文 Agent 可能通过模型结构降低成本和延迟。
- **Miles RL Training Loop**：`SGLang rollout + Megatron policy update + async loop + weight sync`；重要性在于异步执行、状态同步和一致性可启发 Agent Harness。
- **Browser MCP / Browser Use Trace Mapping**：把浏览器会话、动作、权限、安全字段和 resume 字段结构化；重要性在于让 Browser Use 可审计、可复现、可恢复。
- **MCP Production Readiness Checklist**：围绕 timeout、auth、permission、retry、failure trace 设计 MCP 生产化清单；重要性在于把协议接入升级为运行时可靠性。
- **Agentic Coding Runtime**：支持长任务、工具调用、状态恢复、用户接管、产物 review 和 commit/PR 的运行时系统；重要性在于第 8 周学习主线。
