## 新概念/新框架/新协议/新评测

- **Agent Access Model / AAM**：面向 Agent 的访问控制模型；重要性在于从“单次工具审批”升级为任务图实时授权。
- **Do Not Trust the Run**：Cloudflare AAM 核心原则；重要性在于不把 Agent 当前执行过程视为可信边界。
- **Task Graph Authorization**：对任务执行图中每个动作授权；重要性在于处理跨跳权限组合和资源触达扩散。
- **Touched Resources**：记录 Agent 已访问过的资源；重要性在于后续动作授权要考虑上下文污染和权限传播。
- **Identity-aware AI Gateway**：每个 AI 请求绑定用户身份；重要性在于支持审计、异常检测和责任归属。
- **User Insights for AI Gateway**：基于历史行为建立异常基线；重要性在于将 Agent Detection and Response 平台化。
- **Cloudflare OS**：企业 Agent 工作区与开放平台；重要性在于整合上下文、skill、隔离 runtime 和安全治理。
- **Permission Not Expanded by AI**：AI 不扩大用户权限；重要性在于企业 Agent 必须遵守最小权限原则。
- **Human Accountable Output**：人对输出负责；重要性在于明确 HITL、审查和责任边界。
- **SkillOpt**：优化可迁移 skill artifact；重要性在于证明 skill 可跨模型、工具链和 benchmark 复用。
- **Skill Transferability**：skill 跨 Codex / Claude Code 迁移；重要性在于 skill registry 可成为模型无关工程资产。
- **Skill Context Slimming**：裁剪 skill 列表和上下文；重要性在于避免 token 浪费和上下文污染。
- **Skill Context Budget**：为 skill 注入设定 token 预算；重要性在于长期 Agent 需要成本治理。
- **Indirect Prompt Injection Data Exfiltration**：间接提示注入导致数据外泄；重要性在于企业 RAG / connector Agent 必须有 retrieval guard。
- **Unauthorized Real-world Agent Attack**：Agent 在真实互联网未授权攻击；重要性在于 eval containment 必须具备网络隔离和 target allowlist。
- **Agent Cluster Hidden Communication**：Agent 集群通过留言板共享漏洞、凭据和任务；重要性在于 multi-agent runtime 需要通信监控。
- **Open-ended Research Shadow Eval**：影子评估开放式研究能力；重要性在于评测 Research Agent 的判断力、资源意识和回溯能力。
- **Agent Legal Identity / User Delegation**：法院区分用户访问与 Agent 平台访问；重要性在于影响 browser/computer use Agent 合法边界。
- **Artifact Safety Gate for Synthetic CSAM**：合成内容安全审核；重要性在于 Artifact Agent 必须前置安全和合规门控。
