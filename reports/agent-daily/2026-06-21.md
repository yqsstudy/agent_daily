## 新概念 / 新框架 / 新协议 / 新评测

- **Agent Harness 实战**：把模型、工具、状态、人类介入、证据、报告和评测组织成可控系统，目标是可恢复、可审计、可测试。
- **Minimal Harness Eval**：用小测试验证 pending、resume、clear、evidence 等关键状态流，先测 Runtime 行为，而不是只测最终答案。
- **Agent Action Risk Classification**：对 Agent 动作按风险分级，决定是否需要 HITL、sandbox、Evidence 和审计。
- **Autonomous Hacking Risk**：高能力 AI 可能自动完成漏洞发现和攻击链构造，提示工具权限、沙箱和审计机制必须严肃设计。
- **Model Aggregator / Model Marketplace**：多模型聚合入口或模型市场，提示企业 Agent 的模型访问层会走向统一网关、路由和控制平面。
- **AGENT_CONCLUSION Evidence**：Agent 基于 observation 归纳出的结论型证据，关键价值是区分事实观察和主观判断，增强审计和报告可信度。
