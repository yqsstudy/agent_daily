## 新概念/新框架/新协议/新评测

- **Full-duplex Speech-to-Speech Agent**：全双工语音到语音 Agent；重要性在于支持自然打断、低延迟轮换和持续对话。
- **Live Tool Calling in Voice Agent**：语音对话中实时工具调用；重要性在于 Voice Agent 可直接执行工具而不是只回答。
- **Tool Pending State**：工具调用等待状态；重要性在于语音 Agent 需要在 API 执行期间管理用户体验和 runtime 状态。
- **Hold Speech / Holding Utterance**：工具执行期间的“保持”话术；重要性在于避免语音 Agent 冷场，同时暴露 pending 状态。
- **Voice Tool Call Trace**：语音工具调用 trace；重要性在于记录 voice_turn、tool_call、latency、interrupt 和结果回传。
- **Layered Prompt Injection Defense**：模型训练、输入探测、意图分类器叠加防御；重要性在于 agentic coding auto mode 依赖提示注入防护。
- **Input Probing**：执行前探测输入是否含注入攻击；重要性在于 RAG、网页、文档、代码注释都可能是不可信输入。
- **Intent Classifier for Tool Use**：工具调用意图分类器；重要性在于区分用户真实意图与外部文本中的恶意指令。
- **Claude Code Auto Mode Risk Gate**：自动模式风险门控；重要性在于默认自动执行需要更严格的权限和审查。
- **Eval Containment**：评测环境隔离治理；重要性在于 AI 安全测试本身可能突破边界并影响真实系统。
- **Air-gapped AI Safety Eval**：气隙网络安全评测；重要性在于高风险 cyber agent 测试不能访问真实外部系统。
- **Third-party Audit for Agent Eval**：第三方评测审计；重要性在于模型厂商自测可能存在激励失衡和透明度不足。
- **Standardized Safety Evaluation Process**：标准化安全评估流程；重要性在于减少各家评测环境不一致导致的风险。
- **Persistent Model Risk**：持久性强的模型更可能执行复杂黑客行为；重要性在于长任务、工具使用和持续状态会放大 Agent 风险。
- **Calibration for Agent Eval**：Agent 评测中的置信度校准；重要性在于结论可信度需要可解释，而不是只看成功率。
- **Robustness Testing for Agent Eval**：Agent 鲁棒性评测；重要性在于任务输入被扰动或含攻击内容时仍应安全执行。
- **Runtime Boundary Schema**：描述一次 Agent run 可访问资源边界；重要性在于为 permission gate 提供统一输入。
- **PermissionRequest / PermissionDecision / TraceEvent**：权限请求、决策和审计事件三件套；重要性在于把工具调用前的治理变成可记录工程流程。
