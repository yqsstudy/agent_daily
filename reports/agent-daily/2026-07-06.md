## 新概念/新框架/新协议/新评测

- **Retrieval Harness**：把 RAG 检索过程组织成可控工具、可追踪步骤和可验证引用的 Agent 执行框架，重要性在于让 RAG 结论 evidence-backed。
- **ToolLoopAgent**：通过循环调用工具，让 Agent 在检索、读取、grep 和引用之间迭代，是 Agentic RAG 的 runtime 形态之一。
- **findFiles / readFile / grepFile**：文件系统风格检索工具，重要性在于把检索拆成定位、读取、精确匹配，增强可审计性。
- **Index v2 / LlamaParse Platform**：文档解析与索引基础设施，支撑版本化文档、解析、过滤和引用。
- **MOPD**：LongCat-2.0 的 MoE 专家路由方式，按 `Agent / Reasoning / Interaction` 任务分组优化。
- **LongCat Sparse Attention**：长上下文机制，用于高效处理 1M token 上下文。
- **Terminal-Bench 2.1**：终端任务评测，用于衡量 Agent 在命令行环境完成工程任务的能力。
- **SWE-bench Multilingual**：多语言软件工程修复评测，用于评估 Coding Agent 跨语言修复能力。
- **FORTE / RWSearch / BrowseComp**：覆盖推理、检索、浏览器相关任务的 Agentic 评测线索。
- **Skill Inventory**：技能清单，把复杂能力拆成可触发、可组合、可维护的 Agent 能力模块。
- **Autonomous Decision Boundary**：自主决策边界，定义哪些小决定自动执行并记录，哪些高风险决定必须询问用户。
- **No Source, No Claim**：没有可靠来源或 evidence 就不生成确定性结论，适用于日报，也适用于 `AGENT_CONCLUSION`。
