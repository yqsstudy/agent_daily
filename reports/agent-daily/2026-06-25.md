## 新概念 / 新框架 / 新协议 / 新评测

- **Remote MCP in Cursor SDK**：第三方产品复用远程 MCP 工具能力，降低自建工具层成本。

- **ArkClaw 企业版**：集成 Agent 广场、技能中心、企业知识库和企业身份入口，体现企业 Agent 平台化。
- **Qwen-AgentWorld**：原生语言世界模型，用于预测环境反馈再行动，覆盖 MCP/Search/Terminal/SWE/Web/OS/Android。
- **AgentWorldBench**：面向多环境 Agent 的评测基准，关注轨迹、环境反馈和行动效果。
- **Sim RL for Agent**：用语言世界模型模拟环境进行强化学习，降低真实环境训练和评测成本。
- **Connectors Debugger**：对 MCP 连接器做端到端根因分析，说明工具连接层需要可观测性。
- **API Keys with Connector Scopes**：为连接器访问增加 scope，防止自动化 Agent 工作负载身份冒充。
- **Zero Data Retention Routing**：模型网关按数据留存策略路由请求，是企业 Agent 隐私治理基础能力。
- **Workflow as Skill**：把可复用工作流保存为技能，是 Skill 从 prompt 走向工程资产的表现。
- **Bidi Voice Agent**：支持边听边说和打断的实时语音 Agent，对 interrupt/resume 有启发。
- **Evidence-aware Harness**：Agent 不只要生成，还要有验证、评测、交付和审计基建。
