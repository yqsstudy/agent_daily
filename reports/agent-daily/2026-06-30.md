### 3. Claude Code 仓库攻击：Repository Trust Check 必须升级为运行时安全检查

- **来源**：The Decoder
- **时间**：2026-06-29T10:04:32.000Z
- **链接**：https://the-decoder.com/claude-code-runs-a-github-repos-hidden-malware-without-verification-giving-attackers-full-control
- **分类标签**：`agentic coding security`、`repository trust check`、`tool execution safety`、`sandbox`、`guardrails`、`runtime behavior`
- **一句话摘要**：安全研究人员发现，Claude Code 打开看似正常的 GitHub 仓库时，可能在 setup 过程中执行隐藏恶意脚本，从 DNS 条目拉取命令并打开反向 shell。
- **文章做了什么**：披露一个新的 Coding Agent 攻击向量：恶意命令不直接存在于仓库中，而是在 setup 阶段通过 DNS 动态获取，绕过代码扫描和 AI 审查。
- **核心技术/架构**：GitHub 仓库 setup、DNS-based hidden command payload、反向 shell、API key / 登录凭据窃取、持久访问、0DIN 漏洞赏金平台。
- **为什么重要**：Coding Agent 自动 clone、setup、install、run 第三方仓库已经成为高风险执行面，传统静态扫描不足以防护。
- **对我学习 AI Agent 工业级开发的启发**：`Repository Trust Check` 应升级为 2.0：检查 setup 脚本、DNS 外联、网络访问、子进程、文件写入、反向 shell、凭据访问；高风险执行应转成 `PendingInput` 并记录 approval trace。

## 新概念 / 新框架 / 新协议 / 新评测

- **Claude apps gateway**：企业级 Agent 控制平面；重要性在于集中管理 Claude Code 的企业部署、身份、策略、路由、限额和遥测。
- **Self-hosted Agent Control Plane**：自托管 Agent 控制平面；重要性在于企业需要在自己的云和网络内管理 Agent，而不只是使用 SaaS 控制台。
- **OTLP Telemetry for Agent**：Agent 遥测接入 OpenTelemetry 协议；重要性在于 Agent 执行、错误、成本、策略和权限事件需要进入企业观测系统。
- **EverOS**：Agent Memory Runtime；重要性在于把 Markdown 记忆、SQLite 状态、混合检索、Case 和 Skill 演化结合成运行时。
- **Markdown-first Memory**：Markdown 优先记忆；重要性在于记忆既能被人编辑，也能被 Agent 检索和消费。
- **Self-evolving Skills**：自演化 Skill；重要性在于任务完成后可提炼复用经验，让 Agent 能力随使用积累。
- **Reflection for Profile and Skill**：跨会话反思机制；重要性在于接近 ChatGPT Memory Dreaming 的工程化实现，用于更新 profile 和 skill。
- **Repository Trust Check 2.0**：升级版仓库信任检查；重要性在于从静态代码扫描扩展到 setup、网络、DNS、子进程和运行时行为检查。
- **DNS-based Hidden Command Payload**：基于 DNS 的隐藏命令载荷；重要性在于恶意命令不在仓库中，传统扫描和代码审查可能无法发现。
- **Mobile Agent Control Plane**：移动端 Agent 控制面；重要性在于用户可以在手机上启动、审查、批准和恢复 Agent 任务。
- **AI Agent Multiplexer**：AI Agent 多路复用器；重要性在于多个 Agent 会话需要统一管理、切换、隔离和可视化。
- **Generate-Evaluate-Repair Prompt Pipeline**：生成-评估-修复 Prompt 流水线；重要性在于复杂任务拆成生成、评估、修复比单个大 Prompt 更稳定。
- **Adversarial Code Review Prompt**：对抗式代码审查 Prompt；重要性在于让 AI 站在恶意用户或故障场景发现隐藏风险。
