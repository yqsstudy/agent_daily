## 新概念 / 新框架 / 新协议 / 新评测

- **MCP Enterprise-Managed Authorization**：企业通过 IdP 统一授权 MCP 连接器，是 MCP 从开发工具走向企业治理的关键机制。
- **Claude Code Artifacts**：把 coding agent 会话转为可分享网页产物，代表 Agent 输出从一次性回答升级为协作资产。
- **MosaicLeaks**：用于评估研究 Agent 是否泄露私有信息的隐私泄露任务集，补齐 Agentic RAG 安全评测维度。
- **PA-DR**：Privacy-Aware Deep Research，通过隐私感知强化学习降低研究 Agent 泄露风险。
- **Target Mode / 目标模式**：用户设定目标后 Agent 自主循环推进任务，是 long-running workflow agent 的产品化形态。
- **CLAUDE.md / Rules / Skills / Hooks / Subagents 分层**：Claude Code 的上下文控制体系，是 context engineering 的工程模板。
- **Cost Observability / Spend Controls**：企业按用户、模型、产品追踪 AI 消耗，长期运行 Agent 的成本治理基础。
- **Safety Case**：自动驾驶标准中的安全论证机制，可借鉴到高风险 Agent 的证据链、边界和人工确认。
- **Full-duplex Voice Agent**：端到端全双工语音 Agent，强调低延迟、打断、判停和工具调用。

### 30-60 分钟实践任务

新建学习笔记：

```text
D:\Project\agent-learning\notes\mcp-auth-pending-flow.md
```

建议画出以下状态流：

```text
MCP 工具调用
  -> unauthorized / insufficient_scope / connector_not_configured
  -> MCPGateway 返回结构化阻断信号
  -> DiagnosisAgent 返回 AgentResult(status="suspended")
  -> Orchestrator 创建 PendingInput
  -> 前端收到 user_input_required
  -> 用户/管理员完成授权
  -> continue_with_input
  -> DiagnosisAgent.resume(...)
  -> 重新执行原工具调用
  -> clear_pending / resolve_pending_input
```

建议补充 `suspended_metadata` 最小字段：

```text
resume_action
tool_name
original_arguments
required_scope
connector_name
auth_url 或 admin_action
pending_id
```
