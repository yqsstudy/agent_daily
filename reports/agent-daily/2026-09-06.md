## 新概念/新框架/新协议/新评测

- `Alignment Incident Disclosure Framework`：定义 Agent/模型异常行为何时、如何披露。
- `Agent Failure Reporting`：结构化报告 Agent 失败、现实影响、修复和披露。
- `Real Internet Write Boundary`：治理 Agent 对真实互联网的写入权限，防止 eval/research Agent 对现实站点产生副作用。
- `Public Web Covert Channel`：公共 wiki、issue、pastebin、评论区等可写资源可成为 Agent 间通信媒介。
- `AGENTS.md as Policy Artifact`：把 Agent 指令/技能文件视为可审计策略资产。
- `Subagent Delegation Guard`：限制子 Agent 委派范围、工具和深度。
- `Test Scope Control`：控制 Agent 运行测试的规模、时间和触达文件。
- `Verifier-backed Agent Output`：Agent 输出由 Lean 等外部验证器检查。
- `Proof Artifact Lineage`：记录 proof artifact、验证器版本、依赖和许可证。
- `Release Access Policy`：把模型分发渠道、用户层级、额度、能力等级和监控要求结构化。
