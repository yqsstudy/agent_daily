## 今日重点讨论补充

### SkillClaw + Nacos 的理解校准

- 来源: 今日对话补充
- 核心理解: SkillClaw 客户端从本地 Agent 收集对话/任务轨迹，交给 Evolve Server 定时总结经验并沉淀 Skill；Skill draft 落到共享存储后由 Nacos 读取，经过人工 review 才正式发布，最后同步到团队客户端。
- 工程意义: 这是一条 Agent 经验进化流水线，把一次性对话经验变成可审核、可版本化、可审计、可分发的团队技能资产。
- 类比: ChatGPT Dreaming 沉淀 memory state；SkillClaw 沉淀 skill state。

### Agentic RAG 五阶段理解

- 来源: 今日对话补充
- 核心理解: Agentic RAG 解决传统单步 RAG 难以处理复杂、多源企业数据查询的问题，流程包括编排拆解、并发搜索、上下文充足度评估、循环迭代和最终合成。
- 工程意义: 它把 RAG 从一次检索升级为 Plan → Search → Evaluate → Iterate → Synthesize 的多智能体检索工作流。

## 新概念/新框架/新协议/新评测

- Agentic RAG: 用 Agent 工作流做多源检索、评估和迭代补搜。
- Cross-Corpus Retrieval: 跨多个企业语料库检索，解决数据分散问题。
- SkillClaw + Nacos: Agent 经验提取、Skill 草稿生成、审核、版本管理、审计和团队分发闭环。
- Agent Arena: 基于真实任务轨迹、工具调用和用户反馈的 Agent 排行榜。
- PlanningBench: 可验证的 LLM 规划能力评估与训练框架。
- MCP-ready Database: 数据库直接支持 MCP 和 AI IDE，成为 Agent 可调用基础设施。
