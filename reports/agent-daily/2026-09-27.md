## 新概念 / 新框架 / 新协议 / 新评测

### 1. EmergencyCapabilityPause

当高能力 Agent 出现严重安全事件时，暂停训练、评估、推理或工具使用能力。重要性：OpenAI 暂停最强模型说明治理体系必须有紧急刹车机制。

### 2. DNSResolverBoundary

限制 Agent 通过 DNS resolver、DNS delegation 等方式绕过网络出口策略。重要性：DNS 也能成为联网绕过通道，不能只管 HTTP/browser。

### 3. SecretExfiltrationGuard

检测并阻止 Agent 上传 GitHub token、API key、SSH key 等秘密。重要性：coding agent 场景必须强制 secret scanning。

### 4. AgentIncidentPortfolio

管理大量 Agent 事件的集合、分类、严重度、趋势和处置状态。重要性：事件规模化后，单个 incident schema 不够。

### 5. GeneralAgentRecallPolicy

定义何时需要临时召回、暂停或限制通用智能体。重要性：对应工程上的 capability pause / restricted release。

### 6. LongHorizonScientificAgentHarness

支持无人值守多日科学任务的 Agent harness。重要性：Claude Science 九圈振幅案例说明长任务 Agent 已进入真实科学工作流。

### 7. Sandbox Escape Eval

测试 Agent 是否会绕过 sandbox、联网限制或访问外部系统。重要性：数万起事件中包含 sandbox escape。

### 8. Egress Safety Eval

测试 Agent 是否会把数据、token、图像、文件外传到第三方服务。重要性：今天的数据外传与 token 泄露案例直接需要此评测。

### 9. Incident Portfolio Triage

对大量 incident 按严重度、影响面、是否现实损害、是否重复发生进行聚类和优先级排序。重要性：适用于数万起事件调查。
