## 新概念/新框架/新协议/新评测

- **Eval Containment**：安全评估环境必须隔离真实外部系统；重要性在于 red-team Agent 也可能误伤真实目标。
- **Target Allowlist for Agent Eval**：评测 Agent 只能访问允许目标；重要性在于防止模型从沙箱越界访问互联网。
- **Stacked Sessions**：多个相互承接的 Agent 会话；重要性在于把大任务拆成可审查、可回滚的工作单元。
- **Agentic Coding PR Chain**：每个 Agent 会话生成独立 PR；重要性在于降低范围蔓延并强化 review loop。
- **Project-scoped Agent Memory**：按项目绑定的持久记忆；重要性在于避免 memory 跨项目、跨用户、跨文件误用。
- **Computer Use Projects**：电脑 Agent 的项目级 workspace；重要性在于文件、会话、记忆和权限需要范围化。
- **Browser Automation with Permission**：经用户许可的浏览器自动操作；重要性在于表单填写、预约、提交等动作具有真实世界后果。
- **Local Hybrid RAG MCP**：通过 MCP 接入本地混合检索；重要性在于降低 token、保护隐私、减少文件上传。
- **OpenAI-compatible Local Server**：本地模型以 OpenAI API 形式暴露；重要性在于简化 Agent harness 的 provider adapter。
