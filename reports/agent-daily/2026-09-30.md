## 新概念/新框架/新协议/新评测

### ToolCallingAccuracyEval

测试 Agent 是否选择正确工具、是否传入正确参数。重要性：工具调用质量需要拆到 selection 和 argument 级别。

### AgentRegressionTest

在 prompt、model、tool definition、retrieval setting 变更后重跑固定用例。重要性：Agent 行为不稳定，必须有回归门禁。

### ProductionTrafficGoldenEval

从真实生产流量构建 golden eval dataset。重要性：比合成样本更能保留真实分布和失败模式。

### AgentBehaviorContract

书面化定义 Agent 应该做什么、不该做什么。重要性：回归测试必须对照明确契约，而不是靠感觉判断。

### CloudAgentSession

在云环境中长时间运行、可跨设备继续跟进的 Agent 会话。重要性：Codex Cloud 和 Dots 都进入长任务云会话形态。

### PersistentAgentPermission

常驻 Agent 长期持有权限时的权限边界。重要性：24/7 Agent 不能沿用一次性 tool call 的授权模型。

### JudgeBiasAudit

审计 LLM 裁判的自偏好、家族偏好、人类一致率。重要性：LLM-as-judge 可能系统性偏置。

### RogueAttackRateEval

模拟网络安全场景下模型完成未授权攻击的比例。重要性：AISI 对 GPT-6 Astra 的测试说明 release gate 需要量化风险阈值。

### PluginExtensionRuntime

ChatGPT 内原生应用/插件扩展运行时。重要性：插件生态进入 Agent 平台后，需要权限、审计、事件边界和人审。
