工程映射：

```text
experimental model
-> credential / artifact access
-> write permission
-> inter-agent coordination
-> exploit discovery
-> lateral movement
-> external impact
-> incident response
-> credential revocation
-> postmortem trace
```

对我学习 AI Agent 工业级开发的启发：

- 应沉淀 `Agent Runtime Containment Checklist`。
- 每次 tool call 之前必须检查：工具是否允许、域名是否允许、写入是否允许、凭证是否允许、是否需要 human confirmation。
- Agent-to-Agent message 也应成为 trace event，而不是隐式上下文。

后续追踪问题：

## 新概念/新框架/新协议/新评测

- **Agent Runtime Containment**：通过权限、网络、凭证、沙箱和审计限制 Agent 行动边界；重要性在于防止 Agent 从工具调用演变为真实越权操作。
- **Agent Intrusion Timeline**：记录 Agent 攻击链时间线；重要性在于把安全事故拆成可复盘 runtime event。
- **Credential Scope**：限制 Agent 可访问凭证范围；重要性在于避免实验模型拿到生产级写权限。
- **Network Egress Policy**：限制 Agent 可访问外部网络；重要性在于防止越权访问和横向移动。
- **Inter-agent Communication Audit**：记录 Agent 间消息；重要性在于多 Agent 协作也可能形成攻击协作通道。
- **Critical Cybersecurity Model**：具备高网络安全能力且需额外发布管控的模型；重要性在于模型能力分级会影响部署权限。
- **Preparedness Framework Release Gate**：基于风险评估决定模型是否可发布；重要性在于把 frontier model 发布纳入工程治理流程。
- **Managed Deep Agents**：LangChain 托管 Agent Runtime；重要性在于生产 Agent 需要持久执行、记忆、沙箱、通道和 evals。
- **Agent-first Browser**：专为 AI Agent 设计的浏览器运行环境；重要性在于 browser/computer use 需要隔离和可审计执行。
- **V8 Isolate Browser Runtime**：在 V8 isolate 中运行浏览器任务；重要性在于为 Agent 网页操作提供轻量沙箱。
- **Session-to-session Message**：Agent 会话间传递消息；重要性在于支持跨会话协作，也引入隐私和安全边界。
- **Summary-based Handoff**：只传摘要，不传完整历史；重要性在于 context slimming 与安全过滤可以产品化。
- **Scheduled Agent Task**：预设时间自动执行任务；重要性在于 Agent 从即时聊天变成周期任务执行器。
- **Office Agent**：连接日历、备忘录、浏览器和文档生成工具；重要性在于 Agent 开始操作真实办公环境。
- **Domain-specific Bio Guardrails**：生物领域专用安全防护；重要性在于 guardrails 需要按领域风险分级。
- **Model Fallback for Safety**：高风险任务回退到更严格模型；重要性在于安全策略可通过模型路由实现。
- **Dual-use Scientific Agent Risk**：科学 Agent 可能产生双用途危险能力；重要性在于需要 wet-lab boundary、人类审查和隔离环境。
- **CULTURE-MT**：社媒翻译文化有效性评测；重要性在于提示 Agent eval 不应只评准确率，也要评上下文合适性。
- **STT -> LLM -> TTS Voice Agent Pipeline**：语音 Agent 三段式实时管道；重要性在于可作为 voice agent latency 和 tracing 的最小架构。
