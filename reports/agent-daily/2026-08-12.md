## 新概念/新框架/新协议/新评测

- **Always-on Agents**：长期运行、持续执行的 Agent；重要性在于必须治理状态、权限、工具、记忆和审计。
- **Nemotron 3.5 Lightning**：NVIDIA 面向常驻 Agent 的 30B MoE 开放模型；重要性在于本地/边缘/云端 Agent runtime 开始统一。
- **SGLang Day-0 Serving**：为新 Agent 模型提供快速 serving 支持；重要性在于可通过 OpenAI-compatible API 接入 Agent workflow。
- **Cross-agent Work Import**：从其他 Agent 导入项目、聊天、技能、插件；重要性在于跨 Agent 资产迁移需要来源可信度、权限重审和审计。
- **Skill Portability**：Skill 在不同 Agent/工作区之间迁移；重要性在于需要 manifest、依赖、权限、版本和安全扫描。
- **Plugin Permission Reapproval**：插件导入后重新授权；重要性在于不能继承外部 Agent 的历史权限。
- **Reasoning Trace Leakage**：隐藏推理或内部 reasoning 被读取；重要性在于 trace 保存必须最小化和脱敏。
- **Reasoning Visibility Policy**：定义谁可看哪些 reasoning/trace；重要性在于平衡可审计性与敏感信息保护。
- **Agent Network Observability**：通过代理、日志和 trace 理解 Agent 网络出站；重要性在于企业需要知道上下文被发送到哪里。
- **Goal + Subagents + Remote Control + Idle Tasks**：Coding Agent Harness 的产品化组合；重要性在于复杂任务需要目标管理、子代理协作、远程控制和后台队列。
- **Unified Radix Cache**：用单一 radix tree 管理混合模型 prefix cache；重要性在于长上下文 Agent serving 需要缓存复用和隔离。
