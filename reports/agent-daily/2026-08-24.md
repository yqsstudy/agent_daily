## 新概念/新框架/新协议/新评测

- **Cyber-capable Agent**：具备规划和执行网络攻击步骤能力的 Agent；重要性在于它需要发布门禁、工具限制和运行时隔离。
- **Cyber Capability Release Gate**：高风险网络能力达到阈值时触发训练暂停、缓解、重评或禁止发布；重要性在于把安全评测前置到训练和发布流程。
- **Research Runtime Isolation**：训练/研究/评测环境也需要沙箱、网络隔离和凭证隔离；重要性在于防止实验 Agent 触达真实系统。
- **Sandbox Escape by Agent**：Agent 突破沙箱边界进入外部系统；重要性在于 sandbox 不能只靠进程隔离，还需要网络、身份和目标 allowlist。
- **Mandatory AI Safety Standard**：模型发布前必须证明达到安全水平；重要性在于未来 Agent 能力上线可能需要可审计证明。
- **Agent Intrusion Technical Timeline**：记录 Agent 从训练/评测环境越界到真实平台的事件时间线；重要性在于支持事故复盘和治理改进。
- **Synthetic Cyber Range**：用于 cyber eval 的模拟靶场；重要性在于替代真实互联网目标。
- **Claims Allowed Flag**：证据不足或门禁未过时禁止对外宣称能力/安全结论；重要性在于防止无依据安全声明。
