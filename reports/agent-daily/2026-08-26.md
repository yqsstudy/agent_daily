## 新概念/新框架/新协议/新评测

- **Auditable Agent Harness**：可被安全团队审计的 Agent 运行框架；重要性在于验证无后门、权限边界和数据外发。
- **Local Cyber Agent**：本地运行的网络安全智能体；重要性在于可处理敏感代码和云配置，但仍需严格权限与审计。
- **User-editable Memory**：用户可逐条查看、编辑、删除的记忆；重要性在于把 memory governance 从后台策略变成用户可控能力。
- **Cross-product Memory**：跨聊天和 Cowork/工作区共享的记忆；重要性在于提升连续性，同时增加跨上下文污染风险。
- **Memory Freshness Check**：定期检查记忆是否过期或冲突；重要性在于避免旧偏好、旧项目状态误导 Agent。
- **Production RAG Ingestion**：生产级 RAG 数据摄取管道；重要性在于 scheduled ingestion、chunking、embedding、freshness 和失败恢复。
- **Local Private Agent Runtime**：本地设备运行大型 LLM/Agent；重要性在于降低敏感数据外发，但需要本地权限隔离和资源治理。
- **High-stakes AI Decision Support**：用于气象、应急等高风险决策的 AI；重要性在于需要 human-in-the-loop 与 evidence-backed output。
