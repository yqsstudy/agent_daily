## 新概念/新框架/新协议/新评测

- **Google Agent Skills Governance**：把 skill 当成可测试、可持续评估、可规模化维护的工程资产。
- **Skill CI/CD Pipeline**：skill 提交需要 linter、链接检查、AI checklist、提交时 eval 和周期性 eval。
- **Remote MCP Tool in Skills**：skill 优先引用远程 MCP 工具，说明 Skill 与 MCP 正在融合成 Agent 能力层。
- **Cloudflare `@cloudflare/computer`**：为 Agent 提供虚拟文件系统和 isolate / container / browser 多执行环境。
- **Agent Virtual File System**：每个 Agent 有独立文件系统，有助于隔离、回放、清理和 trace。
- **Computer Use Runtime**：把浏览器、文件、代码执行整合为 Agent 可控 runtime。
- **Ori Eval**：低门槛任务级模型评测工具，适合做 provider routing 和 role-based model routing。
- **Orchard Agent Training Framework**：微软面向 Agent 训练与评估的共享基础设施。
- **Real-time Voice Agent Stack**：语音持续流动时仍能推理和调用工具，适合实时助手和客服 Agent。
- **Connector Scope Expansion**：连接器在 Claude Code / Artifacts 间复用，提示权限边界需要重新审视。
- **Programmatic Cost Visibility**：Cloudflare Billable Usage API 这类成本 API 可进入 Agent budget trace。
- **Agent Transparency Label**：AI Act 透明度义务要求 Agent 生成内容和用户交互可标注、可审计。
- **Neuro-symbolic Real-time Control**：实时游戏 Agent 需要生成能力与确定性控制结合。
- **Hardware Agentic Prototyping**：Codex 辅助硬件开发，说明 Agentic Coding 正扩展到物理设备闭环。
- **Context Ownership**：企业 Agent 的核心资产包括数据、提示词、编排、上下文和执行痕迹。
