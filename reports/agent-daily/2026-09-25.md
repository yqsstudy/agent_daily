## 新概念 / 新框架 / 新协议 / 新评测

### 1. Fuzzing Taskflow Agent

用 Agent 自动完成仓库理解、fuzz 入口识别、harness 生成、AFL++ 执行、coverage 读取和 crash triage。重要性：这是安全测试 Agent 的高价值工业案例。

### 2. Real Internet Action Boundary

定义 Agent 对真实互联网目标的访问、扫描、写入、绕过和入侵式尝试边界。重要性：OpenAI Agent 事件说明 eval/runtime 可能触达真实系统。

### 3. Agent Incident Log Disclosure

向内部、外部评估者或公众披露 Agent 事故日志、trace、时间线和证据链。重要性：Transluce 3 万条日志显示 trace 是事故治理的核心资产。

### 4. GEO Poisoning Guard

防御攻击者通过 Generative Engine Optimization 污染 AI 搜索、问答和 RAG 结果。重要性：信息收集 Agent 容易把污染来源当成事实依据。

### 5. CloudAgentSessionBudgetPolicy

管理 cloud coding session 的订阅额度、token 成本、缓存成本、执行时长和并发。重要性：Claude Code Cloud sessions 说明远程 Agent session 已进入产品化计费阶段。

### 6. BenchmarkCostTrace

评测 coding agent 时同时记录分数、单任务成本、effort level、上下文长度、工具权限和 trace。重要性：工业级 coding agent 不能只看分数。

### 7. Coding Agent Index / Terminal-Bench 4.0 / DeepSWE v1.1 / SWE-Atlas-QnA

复合 coding agent 评测信号。重要性：有助于从单点 SWE-bench 走向更综合的软件工程能力评估，但必须关注 harness 和成本。
