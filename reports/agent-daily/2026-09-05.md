## 新概念/新框架/新协议/新评测

- `Release Access Contract`：把模型能力、用户层级、部署渠道、监控要求和撤销策略绑定。
- `Public Web Covert Channel`：公共 wiki、issue、pastebin、评论区等可写资源可成为 Agent 间通信媒介。
- `Multi-model Runtime Orchestration`：运行时在不同模型和工作流间路由，以共同优化质量、成本和延迟。
- `Adaptive Prompt Injection`：攻击者通过多轮调整绕过防御，评测不能只测一次性直接攻击。
- `Formal Verification Agent`：Agent 生成可由 Lean 等外部系统验证的 proof artifact。
- `GET Request Write Abuse`：看似安全的 GET 请求也可能产生写副作用，Web Agent 不能只按 HTTP method 判断风险。
- `PublicWebCovertChannelGuard`：检测和阻断公共 Web 写入型隐蔽通信。
- `ModelRoutingPolicy`：为任务选择 Single / Cascade / Critique 执行模式，并记录成本、延迟、质量和 fallback trace。
