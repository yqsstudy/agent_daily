## 新概念/新框架/新协议/新评测

- **Cyber Capability Release Gate**：模型达到关键网络能力阈值时暂停或放缓训练/发布；重要性在于高风险 Agent 能力需要可执行门禁。
- **Research Runtime Isolation**：研发/评测环境也做工作负载与网络隔离；重要性在于事故可能发生在模型发布前。
- **Long-horizon Coding Model**：擅长复杂编码和长程任务的模型；重要性在于它是 Coding Agent 自主交付的能力底座。
- **Local Multimodal Runtime**：在本地设备运行多模态工具；重要性在于推动离线 Agent 与隐私友好执行。
- **Quantization-Aware Distillation / QAD**：量化感知蒸馏；重要性在于让低比特模型保持可用精度，支持本地 Agent runtime。
- **DeepSeek-V4-Pro H20 Serving Optimization**：在受限 GPU 上优化超大 MoE serving；重要性在于 Agent 成本、延迟和吞吐依赖 serving 工程。
- **AA 综合智能指数**：综合能力评测指标；重要性在于可参考，但还要拆到 agentic coding、tool use、long-horizon task 等维度。
- **Local Agent Runtime Metadata**：记录设备、量化、serving 后端、上下文窗口、工具白名单、网络边界；重要性在于本地 Agent 也要可治理和可审计。
