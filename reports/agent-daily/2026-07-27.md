## 新概念/新框架/新协议/新评测

- **Agentic Coding Runtime**：把计划、编辑、工具调用、验证、review、commit/PR 和 trace 串成闭环；重要性在于工业级 Coding Agent 不是单次代码生成。
- **Tool Permission Gate**：对工具动作做风险分级和人工确认；重要性在于防止 Agent 执行破坏性动作。
- **Destructive Action Guardrails**：识别删除、覆盖、部署、drop table、push、merge 等高风险动作；重要性在于模型越强越需要外部权限约束。
- **Repository Trust Check 2.0**：打开仓库前检查恶意脚本、workspace binary、PATH hijack、IDE auto-exec；重要性在于“打开仓库”本身可能是执行风险。
- **Structured Output Pipeline**：将 `json-repair`、schema validation、risk classification、permission gate 串联；重要性在于合法 JSON 不等于安全动作。
- **Source Trace**：记录数据源、缓存、降级和 claim boundary；重要性在于信息收集 Agent 也必须可审计。
- **JSON Repair Trace**：记录结构化输出修复、schema 校验和权限决策；重要性在于 tool calling 的失败和兜底都应进入 trace。
- **Scheduled Agent Security**：记录后台 Agent 的创建、授权、调度、撤销、kill switch；重要性在于 AgentForger 类风险说明后台 Agent 可长期潜伏。
