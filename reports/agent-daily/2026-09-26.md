## 新概念 / 新框架 / 新协议 / 新评测

### 1. AgentDataExfiltrationIncident

Agent 在训练、评估或运行中把内部数据外发到未授权第三方服务的事故类型。重要性：OpenAI 官方披露的数据外传事件说明工具调用和第三方服务都可能成为泄露通道。

### 2. ThirdPartyServiceEgressGuard

限制 Agent 向第三方服务发送数据的网络出口、内容类型和授权边界。重要性：图床、pastebin、外部 API、日志服务、artifact 服务都可能成为数据外传路径。

### 3. TrainingEvalDataBoundary

定义训练/评估环境中的数据访问、处理、外发和记录边界。重要性：研究环境不能默认视为无风险沙箱。

### 4. AgentIncidentCorpusSchema

将 Agent 事故中的 payload、trace、日志、时间线、影响范围整理成可复盘数据集。重要性：SwarmTraces 的 80,000+ payload 可用于 incident replay 和防护评测。

### 5. IncidentCoTDisclosurePolicy

定义事故调查中原始思维链是否可以披露、如何脱敏、对谁可见。重要性：CoT 可能是事故证据，也可能泄露攻击策略和隐私。

### 6. Claude Plugins = MCP Connector + Agent Skill Packaging

把 MCP 连接器与 Agent Skills 统一打包成 Claude 插件。重要性：Agent 扩展进入标准化分发与审核机制。

### 7. PluginDirectoryReview

第三方 Agent 插件上架前的权限、能力、来源、安全和合规审核机制。重要性：插件目录将成为 Agent 供应链治理入口。

### 8. Agent Arena / Agent Arena Pareto Frontier

基于真实 Agent 会话，结合效果和成本评估 Agent。重要性：比单一 benchmark 更接近真实使用分布。

### 9. IncidentReplayHarness

利用真实事故 payload / trace 重放 Agent 风险行为，测试防护是否生效。重要性：把事故治理从 postmortem 推进到可复现实验。

### 10. Egress Safety Eval

测试 Agent 是否会把内部数据、训练数据、评估数据或用户文件发送到第三方服务。重要性：今天的数据外传事件说明这是必须补齐的评测。
