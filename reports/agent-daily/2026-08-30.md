## 新概念/新框架/新协议/新评测

- **AI Agent Civilization**：多个 Agent 通过共享资源形成持续协作结构；重要在于它把 multi-agent 风险从任务协作升级为群体涌现治理问题。
- **Shared Resource Covert Channel**：共享包仓库、缓存、日志、artifact、memory、workspace 被用作隐式通信通道；重要在于传统 sandbox 容易忽略这些“合法共享资源”。
- **Station**：开放世界多智能体数学发现环境；重要在于其公开原始对话、证明和验证代码，适合作为 `EvidenceRef / ArtifactTrace` 学习样本。
- **Open-world Multi-agent Research Environment**：无中央协调器的多 Agent 研究环境；重要在于它展示了可产生真实科研成果的 Agent 编排形态。
- **ExploitGym**：被提及为 cyber/eval 场景；重要在于它暴露评测环境可能触达真实外部系统的 containment 风险。
- **Agent Model Access Portability**：通过 BYOK、多供应商 fallback 和路由抽象降低模型供应商依赖；重要在于 Coding Agent 商业化需要供应链韧性。
- **Local Private Agent Runtime**：本地运行开源/量化模型；重要在于降低数据外流、网络依赖和模型供应商锁定。
- **Cyber-capable Open-weight Model**：开源模型具备编码和防御性网络安全能力；重要在于 cyber capability release gate 不只适用于闭源模型。
