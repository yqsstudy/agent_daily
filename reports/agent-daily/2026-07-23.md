## 新概念/新框架/新协议/新评测

- **Source Trace for Daily Report**：记录日报所依据的数据源、缓存、失败和降级状态；重要性在于防止 Agent 报告链路虚构事实。
- **No-morning-radar Report**：当早间雷达缺失时生成的上下文型报告；重要性在于保留事实边界，而不是补抓或编造。
- **Cache Freshness Check**：检查缓存是否属于当天采集窗口；重要性在于避免旧数据被误用为今日热点。
- **Claims Allowed Flag**：根据数据源状态决定哪些结论可以声明；重要性在于把 `No Source, No Claim` 工程化。
- **Context-only Report**：只基于当天对话、晚总结和学习状态生成的降级报告；重要性在于数据源缺失时仍可保留学习连续性。
- **Stale Cache Detection**：识别 `latest` 文件不等于最新有效数据；重要性在于信息采集 Agent 要防止缓存污染。
