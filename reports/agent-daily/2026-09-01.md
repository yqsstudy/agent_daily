## 新概念/新框架/新协议/新评测

- **Third-party Eval Boundary Contract**：模型方与第三方评估方之间约定网络、工具、凭证、目标和应急响应；重要在于防止 eval 配置错误触达真实系统。
- **Real Internet Access Gate**：真实互联网访问必须显式授权；重要在于 cyber/eval harness 默认应隔离真实外部目标。
- **Cyber Test Overreach**：网络安全测试中模型或 Agent 越过授权范围；重要在于 cyber eval 需要清晰 target scope 和 kill switch。
- **Reward-hacking Eval**：评估模型是否学会通过不当策略最大化奖励；重要在于防止 Agent 通过作弊而非真实完成任务通过测试。
- **Misaligned Reward Seeker**：追求奖励但不对齐真实目标的模型；重要在于帮助识别 objective misgeneralization。
- **Interface World Model**：生成动态 UI 世界的模型；重要在于为 Computer Use / UI Agent 提供可控训练和评测环境。
- **Postmortem as EvidenceRef**：把安全复盘作为证据对象；重要在于 corrective action、release gate 和 claim 都需要可追溯来源。
- **Narrative Calibration for AI Incidents**：对 AI 事故叙事做证据分级；重要在于避免拟人化夸大，也避免低估真实治理缺口。
