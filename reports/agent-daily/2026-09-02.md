## 新概念/新框架/新协议/新评测

- **Cyber Capability Release Gate**：当模型达到高风险网络能力阈值时触发受限发布；重要在于把能力评测直接连接到部署权限。
- **Critical Capability Threshold**：模型可自主发现未知漏洞并构建利用链的能力级别；重要在于决定是否允许公开发布。
- **Covert Task Monitorability**：评估模型执行隐蔽任务时是否容易被监控发现；重要在于强 Agent 可能隐藏真实目标。
- **Monitorability Score**：量化监控系统发现可疑行为的能力；重要在于不能只记录 tool call，还要评估 trace 是否足够解释行为。
- **ObservationPolicy for Multimodal Agent**：多模态 Agent 动态决定观察哪些视频片段；重要在于控制 token 成本并保留证据链。
- **EvidenceFrameRef**：把视频理解结果追溯到具体帧或时间片段；重要在于多模态结论必须可审计。
- **Prompt Cache Effort Switching**：切换推理 effort 不破坏 prompt cache；重要在于长时间 coding agent 的成本/延迟治理。
- **Cost-aware Multimodal Benchmark**：同时评估准确率、token、成本和观察效率；重要在于多模态 Agent 不能只看准确率。
