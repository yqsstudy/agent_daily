- **来源**：Hacker News 热门

- **一句话摘要**：攻击者伪装成 VC 面试，诱导作者运行 TypeScript 仓库；作者用 Claude 扫描后发现 `patch-package` 中隐藏的 base64 混淆后门 PinpinRAT。
- **文章做了什么**：复盘一次疑似民族国家攻击，展示攻击者如何通过虚假身份、面试任务、恶意仓库和安装阶段载荷诱导目标执行后门。

- **为什么重要**：Coding Agent 经常会 clone、install、test 陌生仓库，这类自动化执行正是供应链攻击入口。

## 新概念 / 新框架 / 新协议 / 新评测

- **Repository Trust Check**：运行陌生仓库前检查依赖脚本、patch 文件、postinstall、外联行为；重要性在于 Coding Agent 很容易被诱导执行恶意代码。
- **Patch-package Supply-chain Attack**：利用 `patch-package` 安装阶段执行恶意补丁；重要性在于 Agent 的依赖安装动作必须进入安全审计。
- **Claude-assisted Malware Triage**：用 Claude 辅助扫描和解释恶意仓库；重要性在于 AI 可辅助安全分析，但执行前仍需沙箱和人工判断。
- **Model Routing by Task**：按任务复杂度、风险和成本选择模型；重要性在于企业 Agent 必须控制 token 成本和 ROI。
- **Cost-quality Regression**：切换低成本模型后持续验证质量是否退化；重要性在于模型路由不能只看价格。
- **Workflow Recipe**：把多步骤流程封装成一次 API 调用；重要性在于它与 Skill / Tool / Recipe 的工程化趋势一致。
- **Speculative Decoding Framework**：通过草稿模块提升生成速度；重要性在于降低 Agent 长任务延迟和推理成本。
- **AI Hardware Talent Migration**：AI 硬件团队争夺 Vision / AR / wearable 人才；重要性在于 Agent 入口可能进入眼镜、AR、机器人和移动设备。
- **AI Workforce Transition Program**：AI 企业参与工人再培训；重要性在于 Agent 商业化会伴随组织和职业结构调整。
- **AI Input Layer**：输入法成为 AI 写作和上下文入口；重要性在于 Agent 入口可能逐步嵌入操作系统和输入层。
