## 新概念 / 新框架 / 新协议 / 新评测

- `Apache Burr`：可靠 AI Agent 应用框架；重要在于提供状态化、可观测、可复现的 Agent 应用组织方式。
- `LSP for Coding Agent`：让 coding agent 使用 Language Server Protocol 获取符号级代码上下文；重要在于补齐纯 grep/RAG 的结构化代码理解短板。
- `Package Firewall`：面向 AI 编程的依赖供应链防护；重要在于给自动装包和代码执行加安全边界。
- `Activity Explorer`：模型调用成本、token、缓存命中率和 Agent 趋势观测面板；重要在于支撑生产 Agent 运行治理。
- `Machine Unlearning Audit`：机器遗忘审计方法；重要在于支持长期记忆与企业知识治理中的“可验证遗忘”。
- `Progressive Disclosure Meta-Tool Gateway`：通过元工具、playbook、状态机和上下文黑板逐步展开内部工具；重要在于把 LLM 工具调用从自由选择变成受控执行。
- `AGENT_CONCLUSION Evidence`：Agent 结论型 evidence；重要在于把 claim 从最终文本中抽出来，形成可审计的 observation -> claim 链路。
