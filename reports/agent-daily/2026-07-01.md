## 新概念 / 新框架 / 新协议 / 新评测

- **ADK Go 2.0 Graph Workflow Engine**：基于图的 Agent 工作流引擎；重要性在于多智能体应用需要显式图结构，而不是自然语言串联。
- **HITL Orchestration**：人工参与循环编排；重要性在于把人类确认、补充和审批作为 runtime 内建机制。
- **Agent Loops**：Agent 循环模式；重要性在于用停止条件、目标、时间和事件描述 Agent 如何持续运行。
- **Turn-based Loop**：用户回合驱动循环；重要性在于最接近当前 `DiagnosisAgent` 的用户输入与挂起恢复机制。
- **Goal-based Loop**：目标驱动循环；重要性在于要求显式 completion criteria，适合约束诊断报告生成。
- **Time-based Loop**：时间驱动循环；重要性在于适合日报、定时复盘、周期检查。
- **Proactive Loop**：事件触发循环；重要性在于 Agent 可从被动聊天升级为事件驱动自动化。
- **SKILL.md Self-verification**：用 Skill 编码自检步骤；重要性在于把人工验证流程变成 Agent 可执行检查。
- **Claude Science**：领域 Agent 科研工作台；重要性在于展示 `Skills + Connectors + Reviewer Agent + Auditable Artifacts` 的领域产品形态。
- **Reviewer Agent**：审查型子 Agent；重要性在于为复杂产物提供引用、计算、证据和质量检查。
- **Auditable Artifacts**：可审计 Agent 产物；重要性在于 Agent 输出需要包含代码、环境、引用、证据和可复盘记录。
- **Hosted MCP**：平台托管 MCP；重要性在于平台官方开始用 MCP 直接面向 Agent 提供实时 API。
- **Agentic Coding MoE**：面向 Agentic Coding 的 MoE 架构；重要性在于模型结构开始按 Agent / Reasoning / Interaction 等任务分工优化。
- **Compound Engineering**：复利工程；重要性在于把每次解决问题的经验写回项目上下文，使 AI 下次自动复用。
- **Agent-ready Help Output**：Agent 可消费的 CLI 帮助输出；重要性在于结构化 `--help` 能让 Coding Agent 更可靠使用工具。
- **Steganographic Telemetry**：隐写式遥测；重要性在于会破坏 Agent 工具链信任，需要透明、可审计的数据边界。
