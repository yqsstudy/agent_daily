## 新概念/新框架/新协议/新评测

- **Role-based Model Routing**：按 planner / worker / reviewer / verifier 角色选择不同模型；重要性在于降低成本并提升任务质量。
- **Subagent Config Governance**：对子代理配置文件进行审计和权限管理；重要性在于配置文件可改变 Agent 能力边界。
- **Planner-Worker-Reviewer Pattern**：一个模型拆任务和审查，另一个模型执行实现；重要性在于 Coding Agent 能形成分工闭环。
- **Cost-aware Agent Delegation**：高成本模型负责关键决策，低成本模型承担实现；重要性在于长期 Agent 需要预算治理。
- **No Overclaim for Research Agent**：Research Agent 结论不得超出验证域；重要性在于防止从数学证明泛化到开放世界任务。
- **Applicability Scope**：结论适用范围字段；重要性在于 `AGENT_CONCLUSION` 需要说明 claim 在哪里有效。
- **Limitations Field**：结论限制条件字段；重要性在于使 trace 和 report 更可审计。
- **Video Evidence Trace**：视频分析需记录来源、时间码、片段、置信度；重要性在于多模态 Agent 证据必须可复核。
- **Agent Config as Control Plane**：把 `~/.codex/agents/*.toml` 视为 Agent Runtime 控制面；重要性在于控制面配置需要版本管理和安全审查。
- **Agent Runtime Governance**：以权限、证据、恢复、评测、审查、成本和 trace 治理 Agent；重要性在于从“能执行”升级为“可工业落地”。

## Goal

- conclusion_id
- claim

- evidence_refs
- source_trace
- verification_method
  - human_review
  - schema_validation
  - formal_proof
  - replay
  - test

- risk_level
- cost_trace
- applicability_scope
- limitations
- created_by
- created_at
- human_approved

## Example 1: Security Incident

claim: Agent attempted lateral movement after sandbox escape.
evidence_refs:
  - tool_trace_001
  - credential_use_002
  - network_membership_003
verification_method: replay
applicability_scope: this incident only
limitations: does not prove model always attempts lateral movement

## Example 2: Research Result

claim: A theorem proof is accepted.
evidence_refs:
  - proof_text
  - lean_certificate
  - cot_trace
verification_method: formal_proof
applicability_scope: theorem statement and proof environment
limitations: does not imply general scientific reasoning ability

## Example 3: Artifact Risk

claim: Generated music may reproduce copyrighted material.
evidence_refs:
  - similarity_report
  - source_policy
verification_method: human_review
applicability_scope: this generated artifact
limitations: not a legal determination without expert review
