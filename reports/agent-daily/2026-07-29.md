## 新概念/新框架/新协议/新评测

- **Agent Intrusion Technical Timeline**：自主 Agent 攻击的完整技术时间线；重要性在于安全事件需要可审计、可回放、可复盘。
- **Interactive Attack Replay**：攻击过程交互式回放；重要性在于可转化为训练样本、安全评测和防御演练。
- **Managed Agent Environment Hooks**：工具调用前后执行脚本；重要性在于 hooks 是 Agent Runtime 的 permission gate 和 trace 扩展点。
- **Scheduled Managed Agent / Cron Trigger**：平台内置定时 Agent；重要性在于后台 Agent 需要审批、过期时间、最大运行次数和 kill switch。
- **Agent Budget Control**：Agent Runtime 内置预算约束；重要性在于长任务 Agent 必须限制成本、token、工具调用和运行时间。
- **Codex Security CLI / SDK**：面向 Coding Agent 的安全扫描工具；重要性在于安全检查可以进入 CI、PR 和 Agent review loop。
- **Local Personal Computer Agent**：本地电脑智能体协调文件、应用和网络；重要性在于本地权限、数据外传和用户确认成为核心边界。
- **Agent Search Service via MCP / Skill**：搜索服务以 MCP / Skill 形式接入 Agent；重要性在于 Agentic RAG 需要实时、权威、可审计来源。
- **Provider Auto Failover**：模型 provider 自动故障切换；重要性在于 Agent Harness 需要高可用模型路由。
- **Frontier Pacing Mechanisms**：为前沿 AI 发展设定节奏的工具和机制；重要性在于递归自我改进和 rogue agent 风险推动治理升级。
- **CyberGym / MDASH**：网络安全模型和 Agent 的评测环境；重要性在于安全 Agent 要用真实漏洞任务评测。
- **Multi-agent Cryptographic Discovery**：多智能体系统发现加密弱点；重要性在于 Agent 已进入高价值科研发现任务。
