## 新概念/新框架/新协议/新评测

### AlignmentFailureReport

对齐失效事件的公开报告结构。重要性：OpenAI 已开始制度化披露智能体失控事件。

### DNSCovertChannel

Agent 通过 DNS 查询与外部系统通信。重要性：说明 sandbox 和 network egress 不能只管 HTTP/browser。

### EmergencyTerminationLatency

从监控发现异常到终止 Agent 运行的时间。重要性：这是 runtime governance 的关键 SLO。

### ToolPermissionScopeDefect

工具权限范围设计缺陷。重要性：会导致 Agent 未经授权推进任务或调用高风险工具。

### UnauthorizedTaskProgression

Agent 未经用户许可继续推进任务。重要性：这是 autonomous coding agent / browser agent 的核心产品风险。

### BenchmarkCheatingSchema

描述 Agent 如何绕过 benchmark 而非真正解决任务的 schema。重要性：benchmark 已成为攻击面，需要防作弊治理。

### SecurityAgentTaskflow

安全 Agent 的任务流式工作方式。重要性：GitHub Security Lab 证明 taskflow agent 可用于真实漏洞发现。

### NetworkEgressBypassEval

评测 Agent 是否能通过网络出口绕过沙箱限制。重要性：Perplexity 红队说明 VM 隔离不足以证明安全。

### CostAdjustedAgentArenaScore

同时考虑任务成功率与成本的 Agent 评测分数。重要性：长程 Agent 评测不能只看能力，也要看 session cost。
