## 新概念/新框架/新协议/新评测

- **Browser Agent Safety Classifier**：在浏览器 Agent 每次动作前判断是否安全且符合用户意图；重要性在于替代一部分逐步人工审批。
- **Targeted Human Approval**：只对高风险动作要求人工确认；重要性在于平衡体验和安全。
- **Browser Agent Action Governance**：对浏览器动作进行权限、风险、证据和恢复建模；重要性在于浏览器动作具有真实副作用。
- **Agent Skills Feedback Loop**：用人类反馈更新技能文件，让 Agent 持续改进；重要性在于把经验转成可复用行为规范。
- **Skill Rollback**：技能更新后可回退到旧版本；重要性在于防止错误反馈固化进 Agent 行为。
- **Privacy-preserving Usage Research**：隐私保护下开放真实 Agent 使用数据给外部研究；重要性在于支持独立评估和行为研究。
- **LLM Citation Poisoning**：通过大量伪内容影响 LLM/RAG 引用来源；重要性在于 Agentic Search 必须验证来源可信度。
- **Provenance Trust Level**：对来源证明设置可信等级；重要性在于 C2PA 等签名也可能被系统级攻击伪造。
- **Voice-to-Action Control Channel**：语音转文本成为实时 Agent 操作入口；重要性在于语音输入也需要权限和确认。
