## 新概念/新框架/新协议/新评测

- `Background Computer Use`：后台电脑操作让 Agent 从前台辅助变成异步委托执行，必须设计中断、回滚和证据链。
- `Hybrid Cloud-Local Agent Runtime`：云端规划、本地执行是企业 Agent 落地的重要形态。
- `Outbound-only Agent Worker`：企业机器只出站连接云控制面，降低入站攻击面。
- `Bidirectional MCP`：工具/环境也向 Agent 发事件，MCP 从调用接口走向运行时交互协议。
- `Harness Engineering`：用编排、沙箱、状态和验证器约束 LLM，是 coding agent 工业化核心。
- `Atomic Boolean Rubrics`：把 judge 标准拆成原子布尔项，提高评测稳定性和可校准性。
- `Tool Output Compression`：降低上下文成本，但必须保留 evidence trace。
- `Commerce Agent Loop`：单模型 + skills/tools + domain policy 的生产 Agent 模板。
