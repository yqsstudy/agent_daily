## 新概念/新框架/新协议/新评测

- **ADLC / Agent Development Lifecycle**：用 Agent 接管更多软件开发生命周期；重要性在于把 Coding Agent 从“写代码”扩展到 triage、修复、CI、review、部署。
- **Cloudflare Agents**：统一管理和追踪部署在 Cloudflare 上的 Agent 会话；重要性在于提供生产级 observability。
- **Agent Tracing with OpenTelemetry**：追踪模型调用、工具执行和 token 消耗；重要性在于支撑调试、审计和成本治理。
- **Local Tracing for Coding Agents**：本地开发时自动捕获 trace，Agent 可查询失败操作；重要性在于让 Agent 具备自我调试环境反馈。
- **Local Explorer API**：供 Agent 查询本地 trace 的接口；重要性在于把 observability 变成可调用工具。
- **Software Factory / Flue**：持久化 Agent 工作流框架，用于 issue triage、复现、修复和预览发布；重要性在于把 Agent 变成持续运行的软件工厂。
- **Stacked PR for AI-generated Code**：把 AI 巨型 diff 拆成可 review 的分层 PR；重要性在于降低 code review 风险。
- **Unified Model Routing Gateway**：在 API Gateway 中做模型路由和请求转码；重要性在于让模型选择成为基础设施策略。
- **NVIDIA SkillSpector**：AI skill 安全扫描工具；重要性在于补齐 Skill Registry 的安全治理。
- **YARA Rules for Skills**：用规则扫描恶意或风险 skill；重要性在于把安全策略落到可执行检测。
- **SARIF for Skill Audit**：用标准安全报告格式输出 skill 审计结果；重要性在于接入 CI 和代码审查系统。
- **CI Policy Gates for Skills**：把 skill 安全检查放入 CI gate；重要性在于防止风险 skill 合入或发布。
- **Responses API in Local LLM CLI**：本地 CLI 支持 Responses API；重要性在于更贴近现代 Agent tool calling 接口。
- **Reasoning Trace in CLI**：显示模型推理轨迹；重要性在于帮助调试 Agent 结论和工具选择，但不能直接等同事实证据。
- **Server-side Tools**：工具调用由服务端处理；重要性在于权限、审计和执行位置需要明确。
- **Database Operations Agent**：面向数据库部署、观测和运维的 Agent；重要性在于 Agent 进入生产运维核心系统。
- **Ambient Intelligence in IDE / Design Tool**：无需 prompt，系统根据上下文给建议；重要性在于 Agent 交互从命令式变为环境感知式。
- **Kernel Agent + App Agent**：多 Agent 分工优化底层算子和上层应用；重要性在于展示工业优化任务的 agentic loop。
- **Sandbox-based CI SDK**：基于沙箱执行构建、lint、测试和部署；重要性在于让 Agent 生成代码后进入可验证流水线。
- **Autonomous System Safety Baseline**：L3/L4 自动驾驶强制安全标准；重要性在于自主系统需要明确安全准入和责任边界。
