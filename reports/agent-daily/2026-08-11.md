## 新概念/新框架/新协议/新评测

- **Local Persistent Agent Model**：面向本地、常驻运行的 Agent 模型；重要性在于本地 Agent 将长期接触文件、工具、记忆和屏幕上下文。
- **Muse Glimmer**：Meta 30B 开放权重 Agent 模型；重要性在于把可靠工具调用、多步推理和本地推理作为设计目标。
- **MCP-Atlas**：Agent / MCP 相关 benchmark；重要性在于可评估工具协议和 Agent 工作流能力。
- **τ-Bench**：多轮交易 / 工具使用 benchmark；重要性在于评估 Agent 在服务/交易任务中的可靠性。
- **SGLang Day-0 Agent Serving**：为 Agent 模型提供首日推理支持；重要性在于本地 Agent 需要高效 serving runtime。
- **Claude Code Auto Mode Permission Mechanism**：自动模式下决定哪些操作可安全运行的机制；重要性在于 Coding Agent 默认自动执行必须配套权限解释。
- **Action Risk Classifier**：判断某个操作风险等级的分类器；重要性在于决定是否允许自动执行或要求人工确认。
- **Agentic RAG Governance**：对结构化数据和文档双源 Agent 查询做权限、血缘和策略治理；重要性在于企业 Agent 不能绕过数据治理。
- **Structured Data Evidence**：结构化查询结果作为证据；重要性在于让 SQL / BI 查询也进入 evidence-backed conclusion。
- **Lineage Ref**：数据血缘引用；重要性在于回答结论需要追踪来自哪些表、文档和转换链路。
- **Policy Decision Ref**：策略决策引用；重要性在于回答时证明权限和合规检查已通过。
- **Qwen-MM-Plugins**：多模态 Agent 插件体系；重要性在于从多模态模型走向多模态智能体工具生态。
- **Multimodal Agent Plugin**：支持图像、视频、文档、3D/CAD 的 Agent 插件；重要性在于工具权限从文本扩展到媒体和工程文件。
- **Service Agent Open Platform**：服务型 Agent 开放平台；重要性在于第三方服务可通过对话接入咨询、推荐、下单和支付。
- **Transaction Agent Permission**：交易型 Agent 权限控制；重要性在于下单、支付、理财等动作必须有确认和追踪。
- **Meeting Agent Tenant Isolation**：会议 Agent 租户隔离；重要性在于会议录音、转写和摘要是高敏感组织数据。
- **Computer Use Benchmark / OSWorld-Verified**：桌面/电脑操作 Agent 基准；重要性在于能力已接近或超过人类，需要同步治理外部副作用。
- **Cyber-specialized Model / GPT-5.6-Cyber**：网络安全专用模型；重要性在于授权漏洞研究需要 containment、审计和访问控制。
- **AI Social Writing Assistant**：社交 AI 帮写和点评；重要性在于 AI 开始介入人际表达，需要边界和透明度。
