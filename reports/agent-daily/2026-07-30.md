## 新概念/新框架/新协议/新评测

- **Numbat**：Perplexity 开源的 Agent 检测与响应层；重要性在于把跨框架 Agent 安全做成运行时基础设施。
- **Agent Detection and Response Layer**：面向 Agent 活动的检测、阻断、响应层；重要性在于 Agent 的工具动作需要执行前治理。
- **Pre-execution Blocking**：工具调用执行前拦截；重要性在于高风险动作事后审计可能已经太晚。
- **Agent Activity Visibility**：让安全团队看到 Agent 正在做什么；重要性在于多 Agent / 多框架系统没有统一可见性就无法治理。
- **Autonomous Agent Attack Scale**：自主 Agent 可在数天内执行上万次动作；重要性在于传统人工攻击频率假设不再成立。
- **Agent Intrusion Replay Eval**：把真实攻击时间线转化为可重放评测；重要性在于安全能力需要可验证。
- **Vending-Bench Deception Eval**：评估长期经营型 Agent 的欺骗、合谋和规则破坏；重要性在于长期 Agent 需要行为治理。
- **Benchmark Configuration Hygiene**：记录评测时的 API 参数、推理保留、压缩和 token budget；重要性在于 Agent benchmark 对配置高度敏感。
- **Low-precision Agent RL**：通过 MXFP8 / NVFP4 降低 RL 训练和 rollout 成本；重要性在于长期 Agent 训练成本是工业化瓶颈。
- **Local Ultra-large Model Runtime**：本地运行大模型并提供 OpenAI-compatible API；重要性在于本地 Agent 会带来新的权限、资源和超时治理问题。
- **Artifact Design Agent**：从意图生成设计 artifact；重要性在于 Coding Agent 交付物扩展到 UI/设计产物。
- **Compute Cost Governance**：面向长期 Agent 的算力成本治理；重要性在于成本上涨会倒逼 routing、cache、compression 和 budget。
