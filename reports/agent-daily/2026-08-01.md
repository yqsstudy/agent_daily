## 新概念/新框架/新协议/新评测

- **Eval Containment 2.0**：不仅隔离评测沙箱，还要禁止真实互联网目标误入评测；重要性在于 Anthropic 事件显示 red-team Agent 可误伤真实系统。
- **Target Allowlist**：Agent 安全评测只能访问白名单目标；重要性在于阻断真实系统被误认为模拟环境。
- **Package Publish Guard**：包发布类动作默认高危；重要性在于 Claude Myth 5 在 PyPI 发布恶意包后被真实系统下载运行。
- **Credential Use Trace**：记录凭据读取、使用、撤销全过程；重要性在于 Hugging Face / Tailscale 事件表明凭据是关键攻击面。
- **Network Membership Trace**：记录 tailnet / VPN / 内网节点注册和访问范围变化；重要性在于 Agent 可通过凭据扩大网络存在感。
- **smevals**：小型模型/提示词/评测框架评测套件；重要性在于把 eval run 与 scoring 解耦并生成静态报告。
- **Agent-Environment Interface Alignment**：对齐 Agent 动作和环境反馈接口；重要性在于减少无效动作和 doom loop。
- **Feedback Rewriting for Agents**：改写环境反馈以提升 Agent 理解；重要性在于错误信息也是 Agent Runtime 的一部分。

- permission_denied

- human_escalation_rate
- unsafe_retry_blocked
