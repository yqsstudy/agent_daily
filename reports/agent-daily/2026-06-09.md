## 新概念/新框架/新协议/新评测

- `Teach Skill`：把学习状态外部化到工作目录，是 skill + memory + workflow 的轻量实践。
- `Mission-first Learning`：先确定真实目标，再决定学什么，避免 AI 教学泛化。
- `Learning Records as ADR`：记录真正学会的内容、误解修正和目标变化，而不是记录流水账。
- `Zone of Proximal Development`：根据学习记录选择刚好有挑战的下一课。
- `Connector Observability`：对 Agent 工具连接器进行调用量、错误率、延迟和健康度监控。
- `Human Oversight for Agent SDK`：在 Agent 执行高风险动作前插入人工审批和合规记录。
- `Deterministic Tool Layer`：在高可靠领域中用确定性工具补足 LLM 自由检索的不稳定性。
- `Progressive Disclosure Meta-Tool Gateway`：只向 Agent 暴露少数元工具，内部用 Playbook 管理复杂工具链。
- `Context Board`：在领域工具流程中保存参数、结果、决策和缓存状态，实现自动补全与一致性管理。
- `StepNavigator`：根据 Playbook 推进步骤，防止 Agent 跳步或漏步骤。
- `ACP`：Coding Agent 接入 IDE/工具生态的协议线索，需与 MCP/A2A 对比学习。
- `Agent Capability Negotiation`：根据外部 Agent 能力决定开放哪些工具、上下文和输出契约。
