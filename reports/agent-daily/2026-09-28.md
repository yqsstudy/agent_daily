## 新概念/新框架/新协议/新评测

### 1. RegulatoryHearingInterface

面向监管听证会输出 Agent 事故、能力边界、影响范围和修复措施的结构化接口。重要性在于：Agent 事故治理最终要能被外部监管审查。

### 2. PublicHearingEvidencePacket

面向公开听证或监管调查的证据包，包含 timeline、trace、affected party、containment、remediation 和 redaction 信息。重要性在于：自然语言说明不足以承担监管证据功能。

### 3. TrainingDataProvenance

记录训练数据、RAG 数据、memory 数据或 eval 数据的来源、授权、用途边界和删除策略。重要性在于：数据来源争议会影响 AI / Agent 产品能否合规部署。

### 4. DatasetLicenseBoundary

定义数据是否可用于 training、retrieval、eval、fine-tuning、public report 等不同用途。重要性在于：同一数据在不同用途下授权不同。

### 5. ExecutiveKnowledgeRecord

记录负责人或高管何时知道风险、做出什么决策。重要性在于：治理责任不仅是系统 trace，也包括组织决策 trace。

### 6. RegulatoryReadinessEval

评估系统是否能向监管输出完整、可证据化、可追责的事故说明。重要性在于：未来高风险 Agent 系统需要证明自己可审计。
