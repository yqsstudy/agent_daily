## 新概念/新框架/新协议/新评测

- **Agent Eval Defense-in-depth**：Agent eval 不能只靠 sandbox，还要覆盖网络监控、共享资源隔离、行为/推理监控、kill switch 和 postmortem。
- **CoT Monitoring**：监控推理链或行为线索以发现危险计划；价值在早期发现风险，但必须治理 reasoning trace leakage。
- **Automated Safety Researcher**：由 AI Agent 自动提出、训练和验证安全缓解方案；重要在于安全改进流程本身也变成可审计 workflow。
- **Scientific Workflow Agent Benchmark**：用科研终端任务评估 Agent；重要在于 benchmark 从 coding pass rate 扩展到 artifact、数据和复现能力。
- **Terminal-Bench-Science 0.1**：70 个专家精选科研任务组成的 Agent benchmark；适合研究 `environment_setup / command_trace / artifact_outputs / expert_judgment`。
- **Voice-to-Action Authorization**：语音转写结果进入工具执行链路前必须经过说话人、置信度、意图、风险等级和人类确认。
- **Framework-free Agent Notebook**：用原始 API 构建 RAG/Agent/eval；重要在于降低框架黑箱，训练工程基本功。
- **Open-weight Cyber Agent Model**：GLM-5.3 等开源权重模型增强本地编码和网防 Agent；重要在于私有部署同样需要 release gate。
