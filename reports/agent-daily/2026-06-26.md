## 新概念 / 新框架 / 新协议 / 新评测

- **Agent Turns**：用于衡量 Agent 工作量的执行轮次，比聊天消息更适合观察真实任务执行。
- **Equivalent Human Work Time**：用等效人类工作时长衡量 Agent 任务规模，可将 Agent 产出转换成组织可理解的价值指标。
- **Mobile Agent Control Plane**：手机作为 Agent 的任务启动、通知、审查和审批入口，说明执行环境和监督入口开始分离。
- **Cross-device Background Agent**：后台 Agent 在开发机执行，用户在移动端控制，长任务需要跨端状态、通知和恢复能力。
- **autoMode.classifyAllShell**：Claude Code 将全部 Bash/PowerShell 命令交给自动模式分类器，说明命令执行需要动态风险分类。
- **OpenTelemetry for Coding Agent**：Claude Code 新增 assistant_response 日志事件，说明 Agent 可观测性正在接入工业标准 tracing/logging 体系。
- **MCP Auth Reconnect**：MCP 服务器认证与重连体验增强，说明工具连接层需要认证生命周期管理。
- **Idle Background Shell Memory Reclamation**：后台 shell 命令空闲内存回收，说明长任务 Agent 需要资源治理。
- **Scaffold RL for Agentic Coding**：强化学习联合优化任务脚手架和最终解决方案，说明 Agentic Coding 不只优化答案，也优化执行框架。
- **Terminal-Bench / NL2Repo / ClawEval**：Agentic Coding 多维评测基准，评测从代码修复扩展到终端操作、仓库理解和工具链能力。
- **Game-to-Real Agent Training**：用游戏操作轨迹训练通用智能体并迁移到机器人，说明 Agent 训练数据从文本扩展到长动作轨迹。
- **Controlled Release for Cyber-capable Models**：高网络安全能力模型采用受控发布与准入审批，说明高能力 Agent 需要分级治理。
- **Marketing Agent Optimization Loop**：营销 Agent 完成生成、测试、分析、优化广告变体闭环，说明领域 Agent 正从内容生成走向业务优化循环。
- **Scheduled Financial Briefing Agent**：金融 Agent 定时生成市场情报简报，说明领域 Agent 需要后台任务、用户资产上下文和风险解释。
- **AI Moderation Deployment Risk**：内容审核 Agent 快速部署可能误伤无害内容，说明自动化治理需要灰度、申诉、人工监督和误伤评估。
