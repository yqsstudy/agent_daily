## 新概念 / 新框架 / 新协议 / 新评测

- `Agent Skill + Local Preview Harness`：让 Agent 生成结构化产物，并用本地预览环境实时验证；重要在于把输出变成可验收 artifact。
- `Managed Agent Scheduler`：托管 Agent 支持 cron 定时运行；重要在于 Agent 开始具备生产自动化任务属性。
- `Vault-backed Agent Environment Variables`：通过 vault 给 Agent 提供安全环境变量；重要在于解决真实服务调用中的密钥边界问题。
- `Custom CLI Agents`：把一次性终端 prompt 封装成可复用 workflow；重要在于让 coding agent 经验可以团队化沉淀。
- `Advisor Server Tool`：低成本模型在关键步骤咨询强模型；重要在于支持成本与质量的动态平衡。
- `Cost / Token Evals`：在评测中加入成本与 token 图表；重要在于工业级 Agent 评估不能只看正确率。
- `agents.md Tool Exposure`：通过文档暴露 Space 可调用 API；重要在于提供一种轻量工具发现与链式调用方式。
- `Progressive Disclosure Meta-Tool Gateway`：只暴露少量元工具，再由 playbook 逐步展开内部能力；重要在于降低 LLM 误调用风险。
