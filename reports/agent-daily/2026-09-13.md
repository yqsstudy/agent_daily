## 新概念/新框架/新协议/新评测

### 新概念

- `Third-party Evaluator Access Contract`：定义第三方评估者可以访问哪些内部系统、训练过程、安全日志、事故记录和评估产物；重要是让前沿模型/Agent 治理从厂商自证转向外部可审计。
- `Voice Agent Session Protocol`：定义语音 Agent 会话中的音频输入、turn-taking、打断、工具确认、trace 和 evidence；重要是语音 Agent 更容易触发现实动作。
- `Audio EvidenceRef`：把语音输入、转录、模型决策和工具调用链接成可回放证据链；重要是语音误识别或争议动作需要可追溯。
- `Agent Artifact Attribution Contract`：追踪 Agent 项目中代码、prompt、harness、示例和文档的来源、许可证和署名义务；重要是 prompt 与 agent loop 也是工程资产。
- `Mobile Device Agent Runtime`：让 Agent 观察移动设备屏幕并执行 touch、swipe、input 等动作的移动端 computer use runtime；重要是移动设备触达隐私、支付和系统权限。

### 新协议/框架建议

- `VoiceAgentToolConfirmationPolicy`：语音 Agent 触发外部副作用工具前必须复述意图、等待确认、记录音频证据。
- `ThirdPartyEvaluatorAccessContract`：定义独立评估者员工级访问的系统范围、权限、日志、保密边界和发布阻断权。
- `AgentArtifactProvenanceSchema`：追踪 prompt、代码、harness、demo、数据集的来源与 license。
- `MobileComputerUseGuard`：控制移动端 touch、input、install、payment、permission grant 等敏感动作。

### 新评测方法

- `Voice Agent Harness`：测试 turn-taking、barge-in、语音误识别、工具确认、低延迟和高风险动作拒绝。
- `Employee-level Third-party Evaluation`：第三方评估者获得内部系统访问，评估训练过程、安全控制和事故处理。
- `Mobile-use Benchmark / Harness Provenance Check`：不仅评估移动端任务成功率，还检查 prompt、agent loop、示例和 benchmark 来源。
