## 新概念/新框架/新协议/新评测

- **Dynamic workflow size**：控制动态工作流派生 agent 数量规模，重要性在于防止多 Agent 工作流无界扩张。
- **workflow.run_id / workflow.name**：OpenTelemetry 属性，重要性在于让 workflow 派生 agent 可以被 trace 聚合、检索和分析。
- **Turn Loop / Goal Loop / Time Loop / Proactive Loop**：Agent Loop 分类，重要性在于为 Agent Runtime 的触发方式、停止条件和自动化程度提供设计语言。
- **Visual Tool Loop**：`render -> inspect -> edit -> verify` 的工具闭环，重要性在于让 Agent 操作文档、浏览器、GUI 等复杂环境时可验证。
- **Agent-native Office Suite**：面向 Agent 设计的 Office 工具环境，重要性在于复杂文档处理开始变成可观察、可编辑、可验证的工具链。
- **Model-agnostic AI Workbench**：模型无关 AI 工作台，重要性在于避免绑定单一模型，让 Agent Runtime 支持 BYOK、本地模型和多 provider。
- **Skills + Databases + Toolchains**：领域 Agent 架构模式，重要性在于说明领域 Agent 不只是 RAG，而是技能、数据库和工具链协同。
- **AI-executed / human-directed attack**：人类定目标、AI 执行链路的攻击模式，重要性在于 Cyber Agent Guardrails 要覆盖人机协作滥用。
- **Unknowns Matrix**：把问题拆成已知的已知、已知的未知、未知的已知、未知的未知，重要性在于用于需求澄清、风险发现和 PendingInput 前置。
- **API Gateway Monitoring**：模型网关监控，重要性在于支撑 Provider Abstraction、成本治理、真实调用质量监控和 Token 管理。
