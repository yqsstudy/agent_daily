## 新概念/新框架/新协议/新评测

- `OKF (Open Knowledge Format)`：用 Markdown + YAML metadata 表达 Agent 可消费上下文；重要在于将知识资产格式化、版本化和可迁移。
- `Vendor-neutral Agent Context`：上下文不绑定单一厂商或运行时；重要在于跨 Agent、跨工具链复用组织知识。
- `Long-running Organization Agent`：长期运行的组织级任务执行者；重要在于要求状态保存、失败恢复、权限、审计和成本治理。
- `Cost-aware Multi-model Runtime`：根据任务阶段和成本动态选择模型；重要在于长期 Agent 的 token 成本会显著放大。
- `Agentic Coding Expertise Pattern`：人类负责做什么与验收，Agent 负责怎么做与执行；重要在于为后端开发者转型 AI 应用开发提供协作范式。
- `Skill + Local Render Harness`：用本地环境验证并导出 Agent 产物；重要在于让 Agent 输出可运行、可验证、可交付。
- `ClawEval / Pass3`：任务达标率与成本指标化；重要在于 Agent 评测从模型分数转向工作流成功率。
- `Public Eval for Deployment Misalignment`：用公开数据预测真实部署风险；重要在于提示 Agentic 任务需要更真实的工具环境评测。
- `Consumer HITL for Financial Actions`：支付/资金变动必须人工确认；重要在于高风险工具调用需要显式 guardrail。
