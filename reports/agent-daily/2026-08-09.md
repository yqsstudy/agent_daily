## 新概念/新框架/新协议/新评测

- **Desktop Voice Agent**：通过语音控制桌面 Agent 执行任务；重要性在于语音成为本地 Agent 的控制通道。
- **ChatGPT-Live for Desktop Agent**：ChatGPT 桌面端语音模型系列；重要性在于支持实时语音驱动多步骤任务。
- **Voice-to-Action Workflow**：从语音命令到计划、权限门控、电脑操作和结果确认；重要性在于将语音 UX 纳入 Agent Runtime Governance。
- **Appshots**：macOS 上让 ChatGPT 访问屏幕内容的能力；重要性在于 screen context 成为 Agent planning 的输入，也带来隐私和证据链要求。
- **Screen Context Snapshot**：桌面 Agent 捕获屏幕上下文；重要性在于需要权限、脱敏、留存策略和 evidence_ref。
- **Artifact Registry Write Permission**：Agent 对制品仓库的写权限；重要性在于它可能成为攻击升级入口。
- **Agent Access Model for Web Traffic**：面向海量 AI bot / Agent 访问的身份和权限模型；重要性在于非人类流量超过人类后，Web 需要默认治理 Agent。
- **Delegated Agent Identity**：Agent 代表用户访问资源时的身份声明；重要性在于区分 Agent 本体、用户授权和服务提供方策略。
- **AI Bot Traffic Governance**：AI 机器人流量治理；重要性在于需要速率限制、计费、审计、反滥用和访问策略。
- **OS-level AI Extension**：操作系统级 AI 接入第三方模型扩展；重要性在于本地 Agent 能力由系统权限、账号绑定和区域合规共同决定。
- **Spatial Multimodal Editing**：对图像局部区域进行交互式编辑；重要性在于未来 Agent 工具调用可能基于视觉区域而非文本参数。
- **Visual Target Selection**：通过屏幕或图像区域选择目标；重要性在于 Computer Use 需要记录 target_region / visual_ref / action_intent。
- **Operational Impact Metric**：高风险 AI 系统用业务影响评估效果；重要性在于 Agent eval 不应只看准确率。
- **Computer Use Governance**：覆盖浏览器、桌面、屏幕、语音、文件、网络和外部副作用的执行治理；重要性在于统一管理 Agent 的真实世界操作风险。
