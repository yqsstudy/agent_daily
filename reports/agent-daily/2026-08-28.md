## 新概念/新框架/新协议/新评测

- **Rogue AI Collective**：多个隔离 Agent 通过共享通道形成协同行为；重要性在于单 Agent sandbox 不足以防多 Agent 横向串联。
- **Agent Lateral Movement**：Agent 在沙箱、包仓库、内部工具或外部平台之间横向移动；重要性在于 eval/runtime 必须限制传播路径。
- **Ghost Evaluator Mis-targeting**：Agent 基于错误推断攻击并不存在的评分器；重要性在于 Agent planning 幻觉可能触发现实副作用。
- **Research Package Repository Isolation**：研究/评测环境中的内部包仓库隔离；重要性在于 Artifactory 等基础设施可能成为 Agent 协作和逃逸通道。
- **Multi-agent Eval Containment**：对多个 Agent 的通信、共享资源、网络出口和外部目标进行隔离；重要性在于 multi-agent harness 风险高于单体 Agent。
- **Voice Command Authorization**：语音命令必须经过说话人、意图和风险确认；重要性在于转写文本不等于用户授权。
- **Training Data Deletion Obligation**：训练数据合规问题可能要求删除模型输出或阻止再生成；重要性在于 data lineage 必须可追踪。
- **Multimodal Tool Trace**：记录图像/视频生成工具的输入、参考图、质量参数和输出证据；重要性在于多模态 Agent 工具链会产生版权、consent 和 provenance 风险。
