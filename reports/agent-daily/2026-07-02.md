## 新概念 / 新框架 / 新协议 / 新评测

- **Background Agent Notification**：后台智能体通知；重要性在于把等待输入、完成和任务状态显式化，方便 HITL 和可观测。
- **Background Agent Auto PR**：后台 Agent 自动 PR；重要性在于 Agent 输出从代码修改升级为可审查工程 Artifact。
- **Agent Worktree Isolation**：Agent worktree 隔离；重要性在于后台 Agent 应在隔离工作区修改代码，降低冲突和污染。
- **`/dataviz` Skill**：数据可视化 Skill；重要性在于 Skill 正覆盖具体专业产物生成和质量检查。
- **Claude in Chrome**：浏览器 Agent 能力；重要性在于 Browser Use 进入主流产品，需要权限、访问策略和 trace。
- **Writing Great Skills**：可预测 Skill 编写方法；重要性在于把 Skill 从 prompt 经验变成可验证工作流设计。
- **Model-invoked vs User-invoked Skill**：Skill 触发类型；重要性在于区分自动触发和用户显式调用，减少误触发和漏触发。
- **Progressive Disclosure for Skills**：Skill 渐进式披露；重要性在于控制模型注意力，只在需要时加载更多上下文。
- **Skill Completion Criteria**：Skill 完成标准；重要性在于防止 Agent 提前结束、输出未验证产物。
- **No-op Test**：无效指令测试；重要性在于检查一句 Skill 指令是否真的改变 Agent 行为。
- **Skill Failure Modes**：Skill 失败模式；重要性在于用 Premature completion、Duplication、Sediment、Sprawl、No-op 审查 Skill 可靠性。
- **AI Agent Crawler Governance**：AI Agent 爬虫治理；重要性在于 Web 开始区分搜索、Agent 实时访问和训练抓取。
- **Provider Abstraction**：模型/算力提供方抽象；重要性在于多 provider 环境下，Agent Runtime 需要路由、配额、成本、回退和质量记录。

```markdown
## Skill Draft: evidence-aware-agent-eval

### Trigger

Use this skill when reviewing whether an AI Agent diagnosis result is evidence-backed, recoverable, observable, and safe to execute.

### Main Steps

1. Check pending/resume lifecycle.
2. Check evidence coverage.
3. Check AGENT_CONCLUSION grounding.
4. Check tool execution safety.
5. Check trace completeness.
6. Check completion criteria.

### Completion Criteria

- Every AGENT_CONCLUSION references at least one Evidence item.
- Every suspended task has pending_id and resume_action.
- Every resumed task resolves or clears pending.
- Every tool call records observation or error.
- High-risk tool execution has approval trace.
- Final report distinguishes facts, assumptions, and suggestions.

### Failure Modes

- Premature completion: report generated before pending resolved.
- Duplication: same evidence repeated without new claim.
- Sediment: stale context affects new diagnosis.
- Sprawl: checklist too broad to execute.
- No-op: checks are vague and do not change output.
```
