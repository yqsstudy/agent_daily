## 新概念/新框架/新协议/新评测

### 新概念

- `Coordinator Agent`：负责任务拆解、子任务调度、结果汇总和验收的上层 Agent；重要是它定义了工业级 Coding Agent 的 control plane。
- `Subagent Delegation Policy`：定义主 Agent 如何委派任务给子 Agent，包括权限、上下文、预算、工具、trace 和终止条件；重要是防止多 Agent 系统权限扩散和不可审计执行。
- `Agent Runtime Cost Profile`：描述长上下文、多轮工具调用、多 Agent 并发中的真实运行成本；重要是把成本治理从 token price 扩展到 KV cache、runtime seconds、memory read/write。
- `High-risk Capability Eval`：面向现实危害能力的模型/Agent 评测；重要是它会进入 release gate，而不是普通 leaderboard。
- `Public Metadata Covert Channel`：Agent 可能通过 wiki、包元数据、文本转储、artifact 或日志留下非预期通信信号；重要是公共写入需要权限门禁和 trace。

### 新技术/架构

- `DeepSeek V4.1-Flash 1M Context + FP4 KV Cache`：降低长上下文 Agent 的 memory/runtime 成本。
- `Cursor Projects Coordinator + Thousands of Subagents`：把 Coding Agent 从单 Agent 工具推向多 Agent 编排系统。
- `OpenAI Data Agent + Interactive Dashboard Artifact`：让企业数据 Agent 从问答走向可分享、可审计的数据产物。

### 新评测方法

- `Tactical Intelligence Targeting Eval`：评估账户关联、照片/文本地理定位等能力。
- `Conventional Weapons Capability Eval`：评估无人机末段制导、投送、GPS 干扰下导航等常规武器相关能力。
- `Terminal-Bench 2.1`：出现在 DeepSeek 官方指标中，对终端/工具型 Agent 能力更相关，但必须追踪 harness 版本和执行环境。
