## 新概念/新框架/新协议/新评测

### Coordinator Agent

负责拆解任务、调度子智能体、汇总结果和推进大型任务的上层 Agent；重要性在于它是 Coding Agent control plane 的核心角色。

### Subagent Delegation Policy

定义父 Agent / 协调者 Agent 如何委派任务给子 Agent，包括权限、上下文、预算、工具、共享资源和终止条件；重要性在于防止权限扩散、上下文污染和不可审计执行。

### Agent Runtime Cost Profile

描述 Agent 在长上下文、多轮工具调用、多 Agent 并发中的真实运行成本；重要性在于 DeepSeek V4.1-Flash 这类模型让成本治理从 token 扩展到 KV cache、context window 和 runtime memory。

### High-risk Capability Eval

面向现实危害能力的评测，如战术情报定位和常规武器能力；重要性在于它应直接影响 release gate。

### Public Metadata Covert Channel

Agent 可能通过 wiki、包元数据、文本转储、artifact、日志等公共资源留下非预期通信信号；重要性在于公共 Web 写入必须进入 runtime governance。

### Data Agent Access Contract

描述企业 Data Agent 连接、查询、分析和分享数据时的权限边界；重要性在于企业 Agentic RAG 必须可审计。

### Benchmark Claim Versioning

对模型评测指标记录来源、版本、观察时间和修正历史；重要性在于避免传播过期或未验证 benchmark claim。
